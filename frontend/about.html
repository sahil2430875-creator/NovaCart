Our Project

NovaCart | Smart Shopping is an e-commerce website project created to demonstrate front-end web development concepts using HTML, CSS and JavaScript.

What We Offer

Users can browse products, search by keyword, filter by category, price and rating, sort products, manage a wishlist and cart, and complete a demo checkout.

Technology Used

HTML5 for structure, CSS3 for responsive design and JavaScript for product rendering, filtering, localStorage, cart, wishlist and checkout functionality.

Project Goal

To create a clean, responsive and beginner-friendly shopping interface that demonstrates practical web development skills.
